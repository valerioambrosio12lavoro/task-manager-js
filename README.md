## Descrizione
Questo progetto è una Single Page Application (SPA) progettata per la gestione efficiente delle attività quotidiane. Sviluppata interamente con tecnologie web standard (Vanilla JavaScript), l'applicazione permette di organizzare i propri task con un'interfaccia moderna e intuitiva.

La particolarità di questo progetto è l'uso della persistenza dei dati: i task non andranno persi alla chiusura del browser o al refresh della pagina, garantendo un'esperienza utente affidabile senza la necessità di un database esterno.
## Funzionalità
Gestione Task: Aggiunta e rimozione di attività in tempo reale con aggiornamento dinamico del DOM.

Persistenza Locale: Implementazione della LocalStorage API per il salvataggio dei dati direttamente sul browser dell'utente.

Design Responsive: Interfaccia ottimizzata per diverse risoluzioni grazie all'uso di CSS Flexbox e variabili CSS.

Interattività: Feedback visivo al passaggio del mouse (hover effects) e gestione degli eventi JavaScript per un'esperienza fluida.

## Tecnologie utilizzate
HTML5: Struttura semantica dell'applicazione.

CSS3: Styling moderno con focus su UX/UI e layout flessibili.

JavaScript (ES6+): Logica applicativa, manipolazione del DOM e gestione dello storage.

## Come eseguire il programma
Non è necessaria alcuna installazione o compilazione.

Scarica o clona la repository.

Apri il file index.html in qualsiasi browser moderno (Chrome, Firefox, Edge, ecc.).
